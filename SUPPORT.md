# Support

Thanks for using FitVision! Here is how to get help and report problems.

## 🐛 Bugs & issues

- Search [existing issues](https://github.com/hhhxwhhh/FitVision/issues) before opening a new one.
- Use the **Bug report** template and include: steps to reproduce, expected vs actual behavior, environment (OS, browser, Python/Node versions), and logs where relevant.
- For security-sensitive problems, follow [SECURITY.md](SECURITY.md) and **do not** open a public issue.

## 💡 Feature requests

- Open an issue with the **Feature request** template.
- Describe the user problem you are trying to solve, not just the technical solution.

## 💬 Discussions

- Use [GitHub Discussions](https://github.com/hhhxwhhh/FitVision/discussions) for questions, usage help, and design ideas that are not yet actionable issues.

## 📚 Documentation

- Start with the [README](README.md) for quick start and architecture.
- See [`docs/`](docs/) for development, deployment, and architecture guides.

## ✅ Before asking

Most setup problems are solved by:

1. Reading [CONTRIBUTING.md](CONTRIBUTING.md) (dev environment).
2. Running `make help` for the available shortcuts.
3. Checking that `.env` / `.env.docker.example` values are filled in for any AI features you use.

We aim to respond to issues within a few business days. Community contributions are always welcome via pull request.
